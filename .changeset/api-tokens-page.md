The Account page now lists your API tokens with when each was made, last used and expires, makes a new one that lasts 1, 7, 30 or 90 days or never, and revokes them, so you no longer have to script a sign-in to get a token. A new token is shown once, with a copy button. Making a token now needs a sign-in from the last few minutes, as deleting a project does, because a token itself passes that check.
